# Crop Suitability Ranking & Agronomic Recommendation Decision System
*AI and Foundation course project*

A **decision-support system** (not just a classifier). For one field it
1. **ranks** crops by a hybrid *Suitability Index* (machine learning + agronomic fuzzy rules),
2. says **how much to trust** the ranking (confidence, "borderline - consider both" flag),
3. ranks again by **your priorities** (TOPSIS over suitability, water fit, risk, optional profit),
4. **explains why** (SHAP + plain-language reasons + limiting factor),
5. gives **what-if advice** ("add ~15 kg/ha N", "raise pH by 1.0") with approximate quantities,
6. keeps working when the farmer has **no soil-test report**.

## Quick start (VS Code)
```bash
python -m venv .venv
.venv\Scripts\activate            # Windows      (Linux/Mac: source .venv/bin/activate)
pip install -r requirements.txt   # app only.  For all experiments: pip install -r requirements-dev.txt
streamlit run app.py
```
The trained model is already in `models/`. If it fails to load (different scikit-learn version) the app retrains it (~10 s).

## Honest scope - read before presenting
* Dataset: Kaggle *Crop Recommendation* - 22 crops x 100 rows, **balanced, clean, synthetic-like, India-centric**. High accuracy here will not carry over fully to messy field data.
* The hybrid **matches** Random Forest / XGBoost on clean accuracy (differences are not statistically significant). Its value is explainability, graded scores, trust signals, and coping with missing inputs.
* The hybrid is **not better calibrated** than XGBoost / Random Forest (see `docs/STEP8_evaluation.md`).
* NPK values are relative, so kg/ha advice is indicative. `EXPERT_OVERRIDES` in `scoring.py` is empty - fill it from a cited source (e.g. FAO EcoCrop) before claiming expert knowledge.
* Profit values in `data/profit_index_ILLUSTRATIVE_DEMO.csv` are **placeholders**, not market data.
